# RE5 Control Plus / RE3Controls 完整中文说明

适用：社区衍生版 `1.9.4`（原名 RE5Plus），基于 RE3Controls v1.9。目标游戏为 Steam《生化危机 5 黄金版》1.2.0、32 位 `re5dx9.exe`。

plus2 修复了 plus1 滚轮切枪误赠送武器给队友的问题。从 plus1 更新时关闭游戏，仅替换 `xinput1_3.dll`，保留已有 INI 即可。已交给队友的武器需要在游戏内取回，补丁不会自动还原背包。

本文根据上游英文说明、当前配置读取代码和本版新增功能整理。配置表的“本包值”是安装包内 `RE3Controls.ini` 的实际预设，不一定等于上游默认值。英文原文保留在源码仓库 `docs/user_README_EN.txt`。安装包为 DLL、双语 INI、README.md 三文件，署名与许可合并在 README.md 中。

## 1. 如何修改 INI

编辑游戏目录中、与 `xinput1_3.dll` 放在一起的 **`RE3Controls.ini`**。本包的 INI 已为每个设置添加中英双语注释。

- 方括号内是分区名，例如 `[Camera]`；同名参数放错分区不会生效。
- 英文分区名、参数名和选项值不要翻译。布尔开关通常是 `1` 开启、`0` 关闭。
- 小数统一使用英文句点，例如 `0.75`。数值后不要写单位或中文说明；注释另起一行，以英文分号 `;` 开头。
- 修改已有条目，不要重复添加同一个分区或参数。`[Controls] Run` 与 `[Keyboard] Run` 是两项独立设置。
- 保存后通常约一秒重新读取；暂停或菜单中可能要回到游戏才生效。`HookDelayMs` 控制启动过程，修改后需要重启游戏。
- 建议先备份自己的配置。游戏键盘绑定在游戏选项中改，不在本 INI 中改。

正确格式示例：

```ini
[Camera]
; 普通视角增加 15 度
FieldOfView=15

[Keyboard]
; 保留原有滚轮变焦，非开镜状态下滚轮切枪
MouseWheelWeapons=1

[Trainer]
; 所有项目默认关闭，无快捷键。
InfiniteHealth=0
PartnerInfiniteHealth=0
InfiniteAmmo=0
NoReload=0
InfiniteGrenades=0
```

**本整合包与上游 v1.9 的预设差异：**

| 设置 | 上游 v1.9 默认 | 本包值 |
| --- | --- | --- |
| `[Camera] FieldOfView` | `0` | `15` |
| `[Camera] AimFieldOfView` | `0` | `10` |
| `[Visual] NoColorFilter` | `0` | `1` |
| `[Performance] FPSLimit` | 无此项 | `144` |
| `[Keyboard] MouseWheelWeapons` | 无此项 | `1` |
| `[Trainer]` 六项 | 无此项 | 全部 `0` |

其余已列出的安装包预设沿用上游。若删除 INI 让 DLL 自动生成，普通/瞄准 FOV 会回到 `0/0`、去黄滤镜回到 `0`；新增的帧率和滚轮仍默认开启。不要把“自动生成配置”误当作“恢复本整合包预设”。

## 2. 安装与功能概览

关闭游戏，备份已有的同名 DLL 与配置，将本包的 `xinput1_3.dll` 和 `RE3Controls.ini` 放到 `re5dx9.exe` 同目录。游戏控制类型建议选 **D**，帧率选 **Variable（可变）**。手柄可保留原有 Steam Input 设置。

本 mod 提供自由过肩相机、相对相机移动、移动瞄准、移动换弹、移动切枪、中心准星、肩位切换、背包打开时移动，以及可选的伤害、速度和镜头设置。本整合版另加入 144 FPS 配置和滚轮切枪，使用上游已有的 FOV 与去黄滤镜实现。

本包无需再加载旧版 RE5Fix。旧版若通过改名 DLL 或插件加载器继续运行，应停用那一份，避免重复修改相同功能。本包不包含旧 RE5Fix 的超宽屏 UI、影片、崩溃及 4096 分辨率限制修复，也没有阴影增强选项。

卸载时移除本 mod 的 DLL 与 INI，恢复原先备份的文件。具体整合范围和验证情况见随包双语 `README.md`。

## 3. 默认操作

### 键盘与鼠标

以下按游戏默认绑定说明；若在游戏中改过按键，以自己的绑定为准。

| 操作 | 按键 |
| --- | --- |
| 移动 | `W/A/S/D`，方向相对于相机 |
| 转动相机 / 瞄准方向 | 鼠标 |
| 瞄准 | 鼠标右键 |
| 射击 / 持刀时挥刀 | 鼠标左键 |
| 持刀 | 按住 `Space` |
| 跑步 | 按住 `Shift`；可改成按一下切换 |
| 瞄准时切换普通 / 快速步行 | 跑步键 |
| 换弹 | `R`，可移动换弹 |
| 快速转身 180 度 | `C` |
| 开门、拾取、体术等互动 | `F` |
| 同伴指令 | `V` |
| 定位同伴 / 瞄准时换肩 | `Q` |
| 背包 | `E`；打开后仍可用 WASD 移动，用鼠标操作物品 |
| 地图 | `M` |
| 相机回到角色身后 | 鼠标中键 |
| 选择背包格子 / 暂停 | `1–9` / `Esc` |
| 威斯克冲刺（佣兵模式） | `左 Shift + X` |
| 本版新增：下一把 / 上一把枪 | 滚轮下滚 / 上滚；开镜时仍用于变焦 |

鼠标灵敏度由游戏内鼠标设置与 `[Keyboard] MouseSensitivity` 共同决定。鼠标反转使用游戏自身设置；`MouseVertical` 调整纵向速度。轻碰鼠标是否从手柄切回键鼠由 `MouseSwitchCounts` 决定。

### Xbox 布局手柄

`L3`、`R3` 分别表示按下左、右摇杆。下表以 `RemapButtons=1`、`RunButton=L3`、`InteractButton=A` 为前提。

| 操作 | 按键 |
| --- | --- |
| 移动 / 自由相机 | 左摇杆 / 右摇杆 |
| 瞄准 / 射击 | `LT` / `RT` |
| 持刀 / 挥刀 | 按住 `LB` / `RT` |
| 互动 / 瞄准时换弹 | `A` / `LT + A` |
| 单键换弹 | `X` |
| 同伴指令 / 快速转身 | `B` / 左摇杆向相机方向拉住时按 `B` |
| 背包 | `Y` |
| 跑步切换 / 瞄准时切换步行快慢 | 按一下 `L3` |
| 相机回正 / 威斯克非瞄准时冲刺 | `R3` |
| 挑衅 | 按住 `R3`，再按 `L3` |
| 定位同伴 / 瞄准时换肩 | `RB` |
| 地图 / 暂停 | `Back/View` / `Start` |
| 快选武器 | 十字键 |

`RunButton=RB` 会交换 L3 与 RB 的跑步、定位同伴和换肩职责。背包移动开启时，左摇杆移动角色，十字键移动物品光标，A 打开物品菜单，RB 查看同伴物品。QTE 按屏幕实际提示操作。

威斯克冲刺期间使用游戏原有镜头：右摇杆控制方向，A 加右摇杆左/右/后可转向，RT 使用膝击。键鼠沿用游戏绑定，默认 Shift + A/D/S 转向，左键膝击。非瞄准时的 R3 冲刺会消耗少量生命值。

## 4. `[Controls]` 控制

| 参数 | 本包值 | 作用与可选值 |
| --- | --- | --- |
| `Enabled` | `1` | 总开关。`0` 停用 mod 的功能；本版 144 FPS 修改和去黄滤镜也恢复原始行为。DLL 仍作为 XInput 代理加载。 |
| `Mode` | `Full` | `Full` 使用完整操作；`MeleeCamera` 仅保留体术自由镜头模式，详见第 13 节。 |
| `RemapButtons` | `1` | 手柄使用上述 RE3 布局。`0` 恢复游戏控制类型自身布局；若不要 X 额外换弹，还需设 `OneButtonReload=0`。不负责修改键盘绑定。 |
| `Run` | `Toggle` | 手柄：`Toggle` 按一下跑步键开始跑，松开方向停止；`Hold` 按住跑步键；`Stock` 使用游戏原有跑步方式，推荐类型 D 下为按住 A。键盘另看 `[Keyboard] Run`。 |
| `RunButton` | `L3` | `L3` 或 `RB`，依赖按键重映射。选 RB 后，L3 改为定位同伴及瞄准时换肩。 |
| `InteractButton` | `A` | 手柄、重映射开启时：`A` 为 RE3 互动；`X` 保留原作 X 互动提示，有提示时 X 互动、无提示时 X 换弹。QTE 保持原提示，键盘仍用游戏互动键。 |
| `OneButtonReload` | `1` | X / 键盘换弹键可直接换弹，无须先举枪。`0` 关闭 mod 的单键换弹；手柄原生瞄准换弹组合仍保留。无法换弹或正在处理相同按键提示时，不强行发出换弹动作。 |
| `QuickTurn` | `1` | 开启 B + 向后方向的快速转身，以及键盘快速转身键。`0` 关闭 mod 的快速转身。攻击、爬梯、抓取等特殊状态不会触发。 |
| `WeskerDash` | `1` | 保留佣兵模式威斯克冲刺：非瞄准 R3 发动，冲刺期间原生转向和镜头生效。`0` 为旧 mod 行为：R3 仅回正镜头，冲刺期间右摇杆/鼠标仅转镜头，不负责冲刺转向。 |
| `StickClicks` | `1` | 保留手柄 R3 + L3 挑衅，以及瞄准时 R3 原生动作，如 RPG-7 NVS 夜视切换。`0` 关闭这些摇杆按压动作；威斯克冲刺由上一项单独控制。键盘挑衅键不受此开关影响。 |
| `KnifeFromAim` | `1` | 按住枪械瞄准时可直接按持刀键切刀，释放后回到枪械瞄准；手柄为 LT 中按 LB，键鼠同理。`0` 需先放开瞄准再持刀。 |
| `InventoryMove` | `1` | 打开背包仍能移动和跑步。手柄物品光标改用十字键；键鼠用鼠标操作物品，站定时跑步键保留背包确认功能。`0` 恢复原作打开背包停止移动。 |

## 5. `[Camera]` 相机

| 参数 | 本包值 | 作用与可选值 |
| --- | --- | --- |
| `FreeCamera` | `1` | 自由过肩相机，移动相对于相机，右摇杆或鼠标环绕角色。`0` 使用游戏原作相机和相对角色的移动。 |
| `Speed` | `180` | 手柄自由相机水平旋转速度，单位度/秒。键鼠速度主要调 `[Keyboard] MouseSensitivity`。 |
| `PitchSpeed` | `90` | 手柄自由相机纵向速度，单位度/秒。 |
| `InvertY` | `0` | `1` 反转手柄自由相机纵向；鼠标反转使用游戏内设置。 |
| `Distance` | `230` | 普通自由相机在肩部旋转支点后方的距离，单位厘米；越大越远。 |
| `Height` | `150` | 普通自由相机旋转支点距角色脚下的高度，单位厘米。 |
| `Shoulder` | `45` | 相机向肩侧偏移距离，单位厘米；换肩时方向翻转。 |
| `Tilt` | `8` | 相机回正时的默认俯仰角，单位度，正数表示向下看。R3 / 鼠标中键回到此角度。 |
| `AimDistance` | `0` | 瞄准镜头沿视线向后移动多少厘米，范围 `0–200`；例如 `60` 为后移 60 厘米。`0` 不后移；超过 200 按 200，负值或无效文本按 0。不作用于狙击镜、火箭筒镜头、固定/载具机枪或体术专用模式。 |
| `FieldOfView` | `15` | 普通视角在游戏原 FOV 上**增加的度数**，范围 `-15–40`，并非最终 FOV。原作通常为 45 度，`15` 即约 60 度。`0` 原始，负数变窄；越界取最近端点，无效文本按 0。 |
| `AimFieldOfView` | `10` | 瞄准视角增加的度数，同样 `-15–40`。游戏原始瞄准 FOV 随武器变化，约 33–40 度。不改狙击镜、火箭筒镜头、固定/载具机枪和体术专用模式。 |
| `TurnSpeed` | `720` | 角色转向移动方向的速度，单位度/秒。与相机灵敏度不同。 |
| `BackStep` | `0` | 自由相机下，向相机方向移动且不跑步：`0` 转身朝相机走；`1` 面向镜头所看的方向倒退。移动换弹、切枪和背包中同样适用；向后跑仍转身。 |
| `FollowPlatform` | `1` | 在船、升降机等平台上随平台转动。`0` 平台转动时相机保持世界朝向。 |
| `MeleeCamera` | `0` | `1` 体术、踢击、踩踏等期间保持自由镜头，不切体术特写，需要 `FreeCamera=1`。**不会**关闭其他 mod 功能，与 `Mode=MeleeCamera` 不同。 |
| `GrabCamera` | `0` | `1` 普通敌人抓取期间保持自由镜头，需要自由相机；体术专用模式也支持。致命抓取、剧情/BOSS 镜头、爬梯、倒地等仍由游戏处理。 |
| `CoverTurn` | `1` | 低掩体蹲伏时，右摇杆/鼠标转镜头也带动角色转向。`0` 只转镜头；需要自由相机，高掩体不变。 |

相机位置与 FOV 是两件事：`Distance` 改普通相机位置，`AimDistance` 改瞄准相机位置，两个 FOV 项改视野角度。想扩大视野可先小幅调 FOV，再决定是否拉远镜头。Speed、位置、TurnSpeed 等项未统一做安全范围限制，建议使用合理正数、小幅调整。

## 6. `[Aim]` 瞄准、准星与移动动作

| 参数 | 本包值 | 作用与可选值 |
| --- | --- | --- |
| `GunWalk` | `1` | 持枪瞄准时可移动。`0` 恢复站定瞄准。 |
| `KnifeWalk` | `1` | 持刀时可移动。`0` 站定持刀。 |
| `ReloadWalk` | `1` | 非瞄准状态单键换弹时继续移动。`0` 站定换弹但不切成举枪镜头；按住瞄准的换弹是否可移动由 `GunWalk` 决定。 |
| `SwitchWalk` | `1` | 拔枪/换武器时保持移动。`0` 恢复原作站定切枪。 |
| `ScopeWalk` | `0` | `1` 狙击镜/火箭筒镜头中也可走。手柄类型 B/D 下，按住定位同伴键 + 左摇杆上下调倍率，调倍率期间停止走动；默认定位键 RB，`RunButton=RB` 时为 L3。键鼠仍用滚轮变焦。`0` 镜内站定，保留原生变焦。 |
| `WalkSpeed` | `1.125` | 持枪瞄准或持刀时的普通步行速度参数，`1.0` 对应原作普通步行动画速度。 |
| `FastWalkSpeed` | `1.875` | 瞄准/持刀时，按跑步键切换到的快速步行速度。它不是普通奔跑速度。 |
| `KnifeSpeed` | `1.5` | 小刀/砍刀攻击速度倍率，`1.0` 原速，`1.5` 为 1.5 倍。不改变枪械射速。 |
| `Crosshair` | `1` | 用屏幕中心准星替代激光，键鼠以 `MouseAim=RE3` 为前提。`0` 回到原生瞄准显示，不再使用 mod 的准星直转逻辑；键鼠还受自身瞄准模式影响。 |
| `CrosshairSize` | `1.0` | mod 准星大小，正数限制在 `0.25–4`；`0.5` 一半、`2` 两倍。`0`、负值或无效文本回到 `1.0`，**不能用 0 隐藏准星**。不改镜内刻线、激光或键鼠持刀小准星。 |
| `DirectHorizontal` | `1` | 准星瞄准时水平输入立即转动视角与角色。`0` 使用原作先移动手臂的水平瞄准区域；键鼠还需看 `MouseAim`。 |
| `AimSpeedX` | `1.0` | 手柄水平瞄准速度倍率，正数范围 `0.25–4`，叠加游戏内瞄准速度。也影响镜内瞄准，游戏仍会按倍率减速。 |
| `AimSpeedY` | `1.0` | 手柄纵向瞄准速度倍率，同上。不用于鼠标灵敏度。 |
| `AimCameraLag` | `0.15` | 手柄瞄准镜头跟随延迟，范围 `0–1`。`0` 无拖后，`1` 为原作手柄约 0.14 秒的拖后，`0.15` 接近原作鼠标跟随感。大于 1 按 1，负值/无效文本回到 0.15。 |
| `CrosshairKick` | `1.0` | 开枪时准星张开的幅度，`2` 两倍，`0` 不张开，连霰弹枪/麦林的原生张开效果也抑制。只影响 mod 准星显示，**不等于武器散布或后坐力**。 |
| `KnifeCrosshair` | `1` | 键鼠持刀时显示游戏原有小准星。`0` 隐藏；手柄本来没有该准星。 |
| `Breathing` | `0` | 手柄：`0` 使用接近鼠标模式的稳定瞄准；`1` 恢复原作手柄呼吸晃动。键鼠本来走游戏鼠标稳定路径，不能保证用此项给鼠标新增晃动。 |
| `Recoil` | `1` | 给手柄启用类似原生鼠标的自动武器镜头上抬/回落。`0` 不再为手柄额外启用此行为；原生鼠标的后坐力仍由游戏保留，不能当作键鼠无后坐力开关。 |

`WalkSpeed`、`FastWalkSpeed`、`KnifeSpeed` 等项没有统一的配置边界校验，建议用合理正数。不要用 `0` 代替功能开关；要关闭移动动作，改对应的 `GunWalk` 等开关。

旧配置兼容项 `[Aim] AimWalk` 仍可读取：只有当 `GunWalk`、`KnifeWalk`、`ReloadWalk`、`SwitchWalk` 缺失时，它才决定缺失项的默认开关。本包已逐项写明，无需再添加 `AimWalk`。

## 7. `[Damage]` 伤害与射速

| 参数 | 本包值 | 作用与可选值 |
| --- | --- | --- |
| `Damage` | `0` | `0` 使用原作动态难度伤害；正值用固定倍率替代原来的玩家伤害缩放，作用于玩家造成的枪械、刀、手雷和体术等伤害。**不是在动态伤害结果上再乘一次**。`1.0` 不等于原版难度；上游以 `1.4` 近似普通难度开局，`3.0` 为更高伤害示例。玩家受到的伤害不变。 |
| `KnifeDamage` | `2.0` | 在固定 `Damage` 基础上额外乘给小刀/砍刀。**仅 Damage 大于 0 才生效**；本包 `Damage=0` 时此项不额外强化刀伤。 |
| `FireRate` | `1.0` | 所有枪械射速倍率，正数范围 `0.5–3`。`1` 原速，`2` 两倍。不改刀和手雷速度。 |
| `ShotgunSpread` | `1.0` | 霰弹散布，范围 `0–1`；`1` 原版，`0.5` 半宽，`0` 弹丸集中同一直线，远距离会很强。越界或无效文本恢复 `1`，不是取最近端点。 |

联机时主机的 Damage、KnifeDamage、FireRate 和 ShotgunSpread 会通过 mod 同步给客机，双方需安装兼容版本并保持 `Sync=1`。旧至 v1.6 或更早的 INI 可能保留 `Damage=3.0`；升级 DLL 不会替你改回 `0`。

## 8. `[Trainer]` 配置功能

这六项替代对应外置修改器的常驻开关，全部只由 `RE3Controls.ini` 的 `0/1` 控制，没有热键，也不会启动额外程序。默认均关闭。

| 键 | 效果 |
| --- | --- |
| `InfiniteHealth` | 补满当前本机角色仍存活时的生命，不会复活死亡/倒地角色。 |
| `PartnerInfiniteHealth` | 补满本机 AI 或分屏队友生命，不修改远程网络玩家副本。 |
| `InfiniteAmmo` | 换弹时不扣备用弹药，动画保留。 |
| `NoReload` | 开火时不扣当前弹匣，已开始的换弹动画不会被取消。 |
| `InfiniteGrenades` | 投掷时不扣手雷，不包括地雷或鸡蛋。 |

这些功能只在 Steam 1.2.0 对应指令字节通过验证时启用；不匹配就会在 `RE3Controls.log` 写明 `unexpected game code, left off`。不要与 FLiNG 或 Ultimate Trainer 同时启用相同项目；RE5Plus 不会还原由外部修改器写入的代码。建议只用于单机/离线或双方明确同意的私人联机。

## 9. `[Movement]` 非瞄准移动

| 参数 | 本包值 | 作用与可选值 |
| --- | --- | --- |
| `MoveWalkSpeed` | `1.0` | 非瞄准普通步行速度倍率，正数范围 `0.5–2`，`1` 原速。 |
| `MoveRunSpeed` | `1.0` | 跑步速度倍率，正数范围 `0.5–2`，`1` 原速。 |

它们不替代 `[Aim] WalkSpeed/FastWalkSpeed`。FireRate、移动倍率、AimSpeed 等正数范围项通常会把正数越界值取最近端点，零或负值退回各自默认值；不要把它们都理解成“0 表示关闭”。

## 10. `[Visual]` 画面

| 参数 | 本包值 | 作用与可选值 |
| --- | --- | --- |
| `NoColorFilter` | `1` | `1` 移除关卡偏黄的区域调色，`0` 恢复原始调色。游戏自己的特殊滤镜仍保留；与旧 RE5Fix 去滤镜实现不完全相同。 |

本版没有阴影质量参数。阴影使用游戏内设置。

## 11. `[Performance]` 帧率

| 参数 | 本包值 | 作用与可选值 |
| --- | --- | --- |
| `FPSLimit` | `144` | **本版新增**。`0` 恢复原始限帧计算；否则填 `30–1000` 的整数，例如 `120`、`144`。无效文本、小数或范围外整数退回原始计算。缺少此项时默认 144。 |

游戏内帧率选 Variable（可变）。VSync、驱动、RTSS 等仍可施加更低上限，显卡性能也可能让实际帧率达不到目标。144 FPS 是游戏帧率目标，不会自动把 Windows 显示器刷新率设为 144Hz。高于原生 120 FPS 的动作、QTE 和联机表现尚需实际验证；遇到问题可改为 `120` 或 `0`。

## 12. `[Advanced]` 启动

| 参数 | 本包值 | 作用与可选值 |
| --- | --- | --- |
| `HookDelayMs` | `3000` | 游戏满足启动条件后，额外等待多少毫秒再安装挂钩。范围 `0–60000`，越界取端点。3000 为 3 秒；启动提示完整性检查失败时可尝试 `10000`。**改后重启游戏生效**。 |

## 13. `[Keyboard]` 键鼠

| 参数 | 本包值 | 作用与可选值 |
| --- | --- | --- |
| `KeyboardMouse` | `1` | `1` 键鼠也启用 mod 的相机、相机相对移动、移动瞄准等；`0` 使用游戏原有键鼠操作，本版滚轮切枪同时关闭。 |
| `Run` | `Hold` | 只管键盘：`Hold` 按住跑步键；`Toggle` 按一下切换跑步。不要用 `[Controls] Run` 调键盘，也不要在此填 `Stock`。 |
| `MouseSensitivity` | `0.75` | 鼠标水平相机与瞄准速度倍率，叠加游戏内鼠标灵敏度；正数范围 `0.1–10`。越大越快，零/负值回到 `0.75`。 |
| `MouseVertical` | `1.0` | 鼠标纵向相对于水平的速度倍率，正数范围 `0.1–10`。零/负值回到 `1`，不是反转；反转在游戏内设置。 |
| `MouseAim` | `RE3` | `RE3` 强制中心瞄准模式；`Game` 使用游戏选项选择的原生鼠标瞄准方式。Game 不保证一定出现“只动手臂”的区域，取决于游戏选项。 |
| `MouseSwitchCounts` | `30` | 手柄使用期间，约四分之一秒内鼠标累计移动达到多少原始计数才切回键鼠，避免轻碰鼠标误切。`0` 用游戏原始规则；范围 `0–100000`。键盘、鼠标按钮或滚轮实际操作可直接切设备。 |
| `MouseWheelWeapons` | `1` | **本版新增**。`1` 下滚下一把、上滚上一把；`0` 关闭。按背包 1–9 格顺序循环，跳过空位与非枪械物品。 |

滚轮切枪只作用于当前键鼠所属的本地玩家，需要 `Enabled=1`、`Mode=Full`、`KeyboardMouse=1`。正常持枪瞄准允许切枪，狙击镜等开镜期间保留游戏原生变焦。背包/菜单、失焦、换弹、切枪动画和特殊动作期间丢弃滚轮输入，不在恢复后补发。每帧最多请求一次，成功请求至少间隔 150 毫秒。只有一把且已装备时不会重复切枪。

## 14. `[Coop]` 联机与体术专用模式

| 参数 | 本包值 | 作用与可选值 |
| --- | --- | --- |
| `Sync` | `1` | 启用 mod 的额外联机同步，传送移动瞄准动作、朝向和相关参数等。`0` 关闭这些额外同步；不是关闭游戏联机功能。建议联机保留 1。 |

双方最好使用同一整合版、相同 Mode。上游协议要求 v1.7 或更新版本；霰弹散布同步需 v1.8 或更新。仅一人安装时，另一端可能看到移动瞄准角色滑行，动作与参数不保证一致。FOV、相机、鼠标灵敏度和 FPSLimit 由各自本机设置；滚轮提交的是游戏原生换武器请求。本版新增功能尚未通过实际联机验收。

### 两个名字相近的选项

- **`[Camera] MeleeCamera=1`**：继续使用完整 mod，只额外让体术时保持自由镜头。
- **`[Controls] Mode=MeleeCamera`**：切换到体术专用模式，原作按钮、相机、激光、瞄准、伤害、刀速等大部分行为恢复，只在体术中使用自由镜头，结束后交回游戏。

体术专用模式使用 Camera 分区中的 Speed、PitchSpeed、InvertY、Distance、Height、Shoulder、FollowPlatform 和 GrabCamera；不应用 AimDistance 和两个 FOV 设置，滚轮切枪也不运行。**本整合版的 FPSLimit 与 NoColorFilter 仍是独立开关**，不会仅因切换 Mode 就自动关闭；若只想保留体术镜头、其余接近原作，可设：

```ini
[Controls]
Mode=MeleeCamera

[Performance]
FPSLimit=0

[Visual]
NoColorFilter=0
```

## 15. 常用调整示例

以下只展示要改的条目，需改到现有同名分区，不要把整段重复追加到 INI 末尾。

### 视野更宽，但不改伤害和速度

```ini
[Camera]
FieldOfView=15
AimFieldOfView=10
AimDistance=0

[Damage]
Damage=0
FireRate=1.0
ShotgunSpread=1.0

[Movement]
MoveWalkSpeed=1.0
MoveRunSpeed=1.0
```

Damage=0 时 KnifeDamage 不生效；刀的攻击速度是另一项，想恢复原速还需将 `[Aim] KnifeSpeed=1.0`。

### 鼠标稍慢，键盘按一下跑步

```ini
[Keyboard]
Run=Toggle
MouseSensitivity=0.60
MouseVertical=1.0
MouseWheelWeapons=1
```

### 保留自由相机，但瞄准、换弹、切枪时站定

```ini
[Aim]
GunWalk=0
KnifeWalk=0
ReloadWalk=0
SwitchWalk=0
ScopeWalk=0
```

### 手柄用 RB 跑步

```ini
[Controls]
RemapButtons=1
Run=Toggle
RunButton=RB
```

此时 L3 定位同伴，瞄准时 L3 换肩。

## 16. 排查与已知限制

**修改似乎没生效：**确认改的是游戏目录的 INI、扩展名不是 `.ini.txt`、参数处于正确分区，且值后没有中文或单位。保存后回到游戏稍等；检查 Enabled、Mode、KeyboardMouse、FreeCamera 等前置条件。高级启动延迟需要重启。

**启动提示 `Program integrity check failed`：**上游说明这是游戏启动保护检测到过早改动代码。可先将 HookDelayMs 改为 10000 后重启，仍失败时结合日志排查其他加载器，必要时用 Steam 验证游戏文件。不要为排查盲目删除不相关 DLL。

**日志：**`RE3Controls.log` 位于游戏目录。本版帧率应出现 `RE5Plus FPS limiter: validated hook` 与 `RE5Plus FPS: 144`，滚轮应出现 `RE5Plus mouse wheel weapons: validated hook`。`feature unavailable` 表示相应代码校验或挂钩没有成功。

**准星和手感：**教程文字仍是原作；同伴看到的仍可能是激光，不是你的本地准星。体术自由相机期间游戏小 HUD 子窗口仍可能显示。移动瞄准有脚步声，但缺少脚步扬尘和水波纹。切换输入设备时游戏自身仍会短暂提示。

**兼容与安全软件提示：**仅面向上述 Steam 32 位版本；不保证旧 GFWL、DX10 或其他修改版 EXE。DLL 未签名且会在游戏进程内挂钩代码，可能被安全软件拦截；遇到提示应记录检测名称并核对文件哈希，不要直接关闭安全防护。本发布包 DLL 不包含开发工具，联机数据沿用游戏网络通道。发布压缩包的 SHA-256 见 GitHub Release 说明，不要套用上游原版二进制哈希。

本版通过了构建、自动测试及部分游戏运行时指令只读核对，尚未完成加载本 mod 后的实际游玩与联机测试。中文说明中的功能行为依据当前源码整理，不代表已逐项完成游戏内验证。
